# QA Automation Project

Автоматизоване тестування UI та REST API за допомогою Playwright і TypeScript.

///////////////////////////////////////////
Встановлення залежностей:
npm install
npx playwright install
///////////////////////////////////////////
Запуск усіх тестів:
npx playwright test
///////////////////////////////////////////
Запуск окремих наборів:
npx playwright test tests/api.spec.ts
npx playwright test tests/example.spec.ts
///////////////////////////////////////////
Перегляд HTML-звіту:
npx playwright show-report
///////////////////////////////////////////
## Покриття тестуванням

API — Restful Booker
- Авторизація з валідними та невалідними даними.
- Створення бронювання.
- Оновлення бронювання.
- Видалення бронювання.
- Перевірка видалення бронювання.
- Оновлення бронювання без авторизації.

UI — SauceDemo
- Успішна авторизація.
- Авторизація з неправильними обліковими даними.
- Авторизація заблокованого користувача.
- Перевірка каталогу товарів.
- Сортування товарів за ціною.
- Додавання та видалення товарів із кошика.
- Оформлення замовлення.
- Перевірка обов'язкового поля First Name.
